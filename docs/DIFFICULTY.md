# 난이도·명칭·포인트 색상 변경

메인 시작 화면과 전체 게임 구조를 유지한 개선입니다. 최신 main `9226f8f`에서 새 브랜치 `feat/strategic-difficulty`로 작업했습니다.

## 새 게임의 규칙

- 초급: 5턴, 3선택. 시작 위험도와 맥락 판단을 조정하고 정답 유형을 바로 표시하지 않습니다.
- 중급: 8턴, 4선택. 후속 사건과 여력 회복을 조합합니다.
- 고급: 챕터 순서대로 12, 13, 14, 12, 15, 14, 13, 15, 14, 12, 15, 15턴. 5선택, 사전 힌트 없음.
- 고급의 직접 조치·추가 조사·범위 제한·여력 회복·독립 검증은 모두 그럴듯하지만 비용·효과가 다릅니다. 이전 전술 반복, 준비도, 누적 노출, 미해결 위험, 압박, 피로가 후속 판정을 바꿉니다.
- 자원이 없더라도 매 턴 요구한 선택지 수를 유지합니다. 대신 자원 부족 상태의 검증에는 효과·가용성·피로 비용이 붙습니다.
- 실패하면 점수와 안전 조건, 실제 실패 턴, 자원 부족·반복 전술·미해결 위험을 설명합니다.

## 챕터별 전개 차이

| 챕터 | 추가 사건의 예 | 운영 제약 |
| --- | --- | --- |
| 피싱 | 정상 공지 오탐, 전달본 검증, 예외 만료 | 출처 검증의 준비도가 중요 |
| 계정 | 공용 기기, 복구 지연, 지원 여력 | 격리의 업무 비용 증가 |
| MFA | 남은 세션, 인증 피로, 복구 예외 | 반복 전술에 강한 적응 |
| 웹 | 캐시 권한, 배포 불일치, 회귀 검사 | 독립 검증 비용과 근거 효과 |
| 탐지 | 로그 지연, 공유 주소, 경보 과부하 | 조사 근거의 효과 증가 |
| 랜섬웨어 | 백업 재손상, 복구 권한, 인력 공백 | 압박 증가, 범위 제한의 효과 |
| 내부자 | 그룹 상속, 대리 승인, 외부 공유 | 격리의 정상 업무 비용이 큼 |
| 클라우드 | 리전 설정 차이, 비밀 회수, 예외 누적 | 검증 비용과 복원 영향 |
| 공급망 | 전이 의존성, 빌드 차이, 자격 노출 | 독립 검증의 비용·준비 효과 증가 |
| 사회공학 | 권위 재사칭, 승인 공백, 신고 지연 | 반복 판단의 위험 증가 |
| AI 피싱 | 도구 판정 불일치, 같은 원본 재전달 | 근거 축적 효과와 반복 비용 |
| AI 모델 | 검색 권한, 도구 대체 경로, 승인 피로 | 누적 압박과 독립 검증 비용 |

## 저장 호환

기존 저장 키 `cyber-duel:v1`, 역할 red/blue, 완료 기록과 퀴즈를 보존합니다. 기존 세션에는 새 규칙을 소급 적용하지 않습니다. 새 세션만 `rulesVersion: 2`, `turnLimit`, `strategy`를 추가합니다. 구 규칙 5턴 세션은 화면에 보존 안내를 표시하고 5턴으로 계속 진행합니다. 새 게임을 선택해서 시작하면 확장 규칙을 적용합니다. 기존 점수는 재계산하지 않습니다.

## 화면 유지

메인 파일 `src/main.tsx`, 기존 `src/style.css`·`src/game.css`, `index.html`, `vite.config.ts`는 수정하지 않았습니다. 첫 화면 PNG도 기준 빌드와 동일했습니다.

게임과 기록 화면의 명칭만 공격/방어로 표시하고, 진홍·청록 색은 역할 라벨·버튼·점수·결과 포인트에 한정했습니다. 전체 다크 배경·레이아웃·기존 애니메이션은 유지합니다. 별도 AI 대응 결과, 상대 행동·이유·점수, 챕터·진행 저장, 아카데미·연구실·API 없는 상대 AI도 유지합니다.

## 핵심 검증

- 기존 121개 검사를 보존하고 새 77개 검사를 추가했습니다. 이전 5턴 규칙의 72개 역할·난이도 조합은 호환 세션으로 계속 검증합니다.
- 새 규칙 12챕터 × 공격/방어 × 초급/중급/고급, 총 72개 경로의 완주 가능성을 검증했습니다. 테스트 전용 제한 탐색을 사용해 현재 상태에 맞는 계획을 선택하며 고정 정답 목록을 제품에 넣지 않았습니다.
- 초급 5턴·3개, 중급 8턴·4개, 고급 12~15턴·5개 선택지가 유지되고 미래 턴 선택은 거부됩니다.
- 이전 선택이 다른 같은 턴의 상대 전략이 바뀌며, 대응 여력 부족은 판정·내 점수·위험도·피로를 바꿉니다.
- 점수와 자원 변화량의 보존, 원본 상태 불변, 지표 범위, 응답 확인 전 중복 선택 차단을 확인했습니다.
- 챕터별 후속 사건이 반복되지 않고 서로 다른 사건·초점을 가지는지 검증했습니다. 고급 턴 길이는 12/13/14/15를 모두 포함합니다.
- 고급에서 회복 전술만 반복하면 실패하며 실제 실패 턴의 행동과 미해결 위험에 근거한 피드백이 나옵니다.
- v1 저장의 기존 5단계·5턴 챕터·점수·퀴즈를 보존합니다. v2의 8턴/14턴 중간 상태와 최종 상태, 자원과 턴 제한을 저장·복원합니다. 잘못된 턴 제한은 거부합니다.
- 메인 시작 화면 파일 5개의 SHA-256이 기준 main과 동일합니다. 기준/수정본의 새 브라우저 첫 화면 PNG가 바이트 단위로 동일합니다.
- 브라우저에서 게임과 기록 화면에 RED/BLUE/TEAM이 남지 않는지, 고급에서 힌트 버튼이 없는지 확인했습니다. 내부 red/blue 값과 과거 원본 기록은 바꾸지 않았습니다.
- 390px/375px 모바일에서 가로 넘침 없음. 대결의 외부 API 호출 0회, JavaScript 오류 0건.

## 검증 한계와 적용 상태

- ‘정말 어렵다’는 체감은 사람의 플레이로 평가해야 합니다. 자동 검사는 완주 가능성과 반복 전술 실패·자원 비용을 확인합니다.

# CYBER DUEL 개선판 검증 기록

현재 클라우드 인스턴스의 로컬 프로덕션 빌드에 대한 기록입니다. 실제 GitHub Pages 배포 성공을 의미하지 않습니다.

## 기준과 실행

- 원격 main: `0311b22c23310c4b906320ea228189dbc10f2802`. 기존 완료된 튜터 작업 `39a9d1b`도 보존하여 새 브랜치 `feat/twelve-chapter-duels`에서 확장했습니다.
- React 19 / TypeScript 5 / Vite 7 / Node.js 24.19.0 / npm 11.9.0 / Chromium.
- `npm ci --cache /tmp/cyber-npm-cache --no-audit --no-fund`: 잠금 파일 기반 설치 성공.
- `npm test`: **121개 통과**, 실패·건너뜀·취소 0개. 기존 46개와 신규 75개.
- `npm run build`: TypeScript 검사와 Vite 배포 빌드 성공.
- `npm run test:browser`: 기존 RED/BLUE 각각 5단계 성공·실패·재도전·저장 복원, SQL 비교, 퀴즈, 연구실, 튜터, 주요 화면 모바일 검증 성공.
- `npm run test:duel:browser`: 12챕터 × 두 역할의 24개 경로·120턴을 실제 UI로 완료, 성공.
- `npm run test:tutor:browser`: 기본 지식 오프라인 답변 및 모의 Gemini 연결/오류/취소·키 비저장 검증 성공.
- YAML 구문 검사 및 `git diff --check`: 성공.

## 신규 상태 전이·상대 AI 검사

- 새 챕터마다 초급·중급·고급 × RED/BLUE, 총 72개 경로에서 5턴 완료와 성공 조건 검증.
- 현재 단계의 3개 선택지만 허용, 고급만 4개. 선행 단계·완료 행동 제외.
- 결과 확인 전 추가 행동 차단, 종료 후 행동 차단.
- BLUE가 선택 전에 공개받은 공격과 결과의 상대 공격 일치.
- 위험도·이전 전술·난이도에 따라 전략 변화. 반복 전술 적응, 오판 경로의 최종 실패 확인.
- 공격/방어 점수 증가량, 이전/이후 지표 차이 일치, 지표 범위 0~100, 원본 상태 불변.
- `fetch`를 실패하도록 대체해도 대결 작동. 브라우저 24개 경로에서 Gemini 요청 **0회**.

## 저장 호환·UI 검사

- 새 필드가 없는 기존 1~5단계의 중간 게임·완료 점수·퀴즈를 같은 키에서 그대로 읽고 재저장.
- 새 ID 101~112를 사용해 과거 기록을 재할당하지 않음. 역할·목록별 순차 해제 유지.
- 신규 결과 화면, 최종 턴, 난이도를 새로고침 후 복원. 최종 확인 뒤 이력·점수·난이도 저장, 대시보드에서 다시 열람.
- 브라우저에서 기존 실제 모양의 v1 세션을 주입하고 이전에 완료한 행동과 미래 행동이 선택 목록에 없는지 확인.
- 결과 화면에서 행동 카드 없음. 다음 버튼을 누른 뒤에만 새 선택 표시.
- 데스크톱 1440px와 모바일 390px/기존 회귀 375px에서 확인. 가로 넘침·JavaScript 실행 오류 없음.
- 전환 애니메이션과 `prefers-reduced-motion` 설정 제공. 별도 스크린 리더 사용성 평가와 모든 브라우저 조합은 미실행.

## 수정 중 발견해 해결한 문제

- 고급 RED의 일부 상황에서 모든 전술이 동시에 차단되던 규칙을 발견. 이전 전술을 예측하는 기본 대응과 현재 위험한 행동에 대한 추가 대응으로 나눠 선택 경로를 유지함.
- 카드에 설명이 추가되면서 접근 가능한 버튼 이름이 바뀌던 문제를 명시적 행동 이름으로 보정.
- 기존 자동 테스트를 새 결과 확인 흐름에 맞춰 갱신하고 과거 목표·실패·재도전 검사를 유지함.

## 외부 검증 한계

- GitHub Pages 사이트 직접 접속은 프록시 HTTP 403으로 차단됨. 저장소 소스와 로컬 빌드를 검증했으며 라이브 사이트를 확인했다고 주장하지 않음.
- 라이브 Gemini 호출은 개인 키 없이 미실행. Gemini 관련 검증은 모의 응답임.
- 실제 공격·OS 명령·DB·방화벽 변경 없음. 모의 데이터와 규칙 기반 상대만 사용.
- main 병합·배포 미실행. PR 검토와 사용자 확인 후에만 배포 가능.

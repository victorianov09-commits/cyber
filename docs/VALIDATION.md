# 검증 기록

이 기록은 현재 클라우드 인스턴스에서 실행한 결과입니다. GitHub Pages의 실제 배포나 환경 발행 후 새 작업 복원을 증명하는 기록은 아닙니다.

## 실행 환경과 결과

- Node.js 24.19.0 / npm 11.9.0 / Chromium.
- `npm ci --cache /tmp/cyber-npm-cache`: 잠금 파일 기반 재설치 성공.
- `npm run build`: TypeScript 검사와 Vite 배포 빌드 성공.
- `npm test`: **46개 통과**, 실패·건너뛴 테스트 0개.
- `npm run test:browser`: 배포 미리보기 서버의 `/cyber/`를 실제 Chromium으로 검증, 성공.
- `npm run test:tutor:browser`: 네트워크를 끈 기본 답변, 모의 Gemini 연결과 오류 복구·키 수명·모바일 검증 성공.
- `git diff --check`: 공백 오류 없음.
- `vite.config.ts`의 `/cyber/`와 기존 GitHub Actions 워크플로 변경 없음.

## 단위·상태 전이 검증

- 5개 미션 × RED/BLUE: 각 성공 경로와 실패·새 게임 재시작.
- 9개 대안 경로, 반복 행동에 대한 AI 반응, 원인 차단 전 복구 비용과 전체 중단의 가용성 비용.
- 선행 조건 미충족 행동 거부, 모든 지표 0~100 유지, 종료 뒤 추가 행동 거부.
- 같은 역할의 다음 단계만 잠금 해제.
- 저장·복원, 손상 데이터·저장 제한 오류 처리.
- 모의 터미널의 허용 목록과 외부 명령 거부.
- 고정 시드 재현, 조정/평가 분리, TP/FP/TN/FN과 지표의 수작업 예제 대조.
- 원시 가상 로그인 이벤트와 집계 특징 일치, 5분 구간 제약.
- SQL 모형에서 정상 입력·교육용 토큰·길이 검증·매개변수 분리 비교.
- 한국어 데모 질문의 자료 선택과 지원 범위 안내.

## 브라우저 검증

- 두 역할 각각 1~5단계 완료, 단계별 첫 행동 뒤 새로고침해 이어서 플레이.
- 새 역할은 1단계만 시작 가능, 완료 후 다음 단계 해제, 역할 간 진행 분리.
- 두 역할의 1단계 실패 → 결과 → 재도전 → 0턴 시작.
- 홈 이어하기, 모의 터미널에서 OS 명령 거부.
- SQL 단계의 입력 비교 보조도구에서 취약 모형 2행 / 매개변수 모형 0행 반환.
- 아카데미 오답·정답 해설, 새로고침 뒤 학습 진도 유지, 로컬 데모 질문 응답.
- 연구실 평가 데이터는 실행 버튼 뒤 공개되고 평가 뒤 임계값 잠김.
- 1440px 데스크톱과 375px 모바일에서 주요 화면 확인. 모바일에서 문서 가로 넘침 없음, 메뉴 열기/닫기와 닫힌 메뉴의 포커스 차단 확인.
- 브라우저 JavaScript 실행 오류 0건.

## 기본 도우미·Gemini 연결 검증 추가

- 71개 자료의 제목 검색, CPU/RAM 비교, DNS·Python·개인정보·인코딩 설명.
- JavaScript/Java, HTTPS/HTTP, GitHub Pages/GitHub의 긴 용어 우선 선택과 짧은 영어 약어의 오인 방지.
- 준비된 자료가 없는 질문에는 설명을 지어내지 않고 범위 안내.
- Gemini 키는 URL과 질문 본문에 넣지 않고 전용 요청 헤더로 전달. 인증·모델·권한·할당량·서버 오류에 한국어 안내.
- 빈 응답·잘못된 JSON·안전 차단·길이 제한·네트워크 오류·요청 취소 처리.
- 브라우저를 오프라인으로 바꿔 기본 지식 답변을 검증하고 외부 API 요청 0회 확인.
- 브라우저에서 모의 인증 실패 후 재연결, 연결 확인 후 질문, 할당량 초과 시 기본 모드 복귀, 요청 중 연결 해제와 오래된 응답 무시 확인.
- localStorage/sessionStorage에 테스트 키 없음. 연결 확인 후 키 입력란 비우기, 새로고침 후 미연결 복귀 확인.
- 실제 API 키 없이 모의 응답으로만 실행했으므로 Google의 모델 지원·과금·실제 CORS/인증 성공을 증명하지 않습니다.

## 남은 외부 절차와 한계

- 기본 도우미는 API 없이 71개 주제의 준비된 자료를 검색합니다. 개인 키로 Gemini REST API에 연결하는 UI와 요청 처리를 구현했습니다. 실제 키를 사용한 Gemini 호출은 검증하지 않았으며 API 관련 테스트는 모의 응답을 사용했습니다.
- 실제 공격·DB·방화벽은 실행하지 않습니다. 연구 수치는 합성 로그에만 해당합니다.
- 접근성은 시맨틱 버튼, 포커스, 상태 알림, 닫힌 메뉴 차단을 확인했습니다. 별도 스크린 리더 사용성 평가나 모든 브라우저 조합을 검증하지는 않았습니다.
- GitHub API 호출은 현재 프록시에서 HTTP 403으로 차단됩니다. Git 읽기 접근 성공과 API 접근은 별개입니다. PR 생성/배포 여부는 따로 확인해야 합니다.
- 환경 초안의 설치/시작 안내와 네트워크 추가는 저장되었습니다. 사용자 환경 설정에서 검토·저장·발행한 뒤 새 작업 복원을 확인해야 합니다.

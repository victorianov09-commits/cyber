# PR 본문

기존 미션 화면은 준비 중 안내만 제공했습니다. 이제 RED/BLUE 역할로 정확히 다섯 단계를 순서대로 플레이하고, 선택에 따른 AI 반응·상태 변화·성공/실패·해설을 확인할 수 있습니다. 공통 엔진과 데이터로 미션을 구성하고 단계 해제, 이어하기, 역할별 기록과 퀴즈 진도를 브라우저에 저장합니다.

기존 홈·아카데미 디자인과 `/cyber/` 경로, GitHub Pages 워크플로는 유지했습니다. 12개 개념 학습과 로컬 데모 튜터, 가상 SQL 입력 비교, 별도 조정/평가 데이터로 탐지 규칙 A/B/C의 혼동행렬·지표를 계산하는 연구실을 추가했습니다. 실험 시드·임계값·원시 이벤트·결과를 JSON으로 내려받을 수 있습니다.

검증: `npm ci`, `npm run build`, 자동 테스트 39개 통과. 실제 Chromium에서 RED/BLUE 각각 5단계 완료와 새로고침 복원, 실패·재도전, 역할별 잠금, 퀴즈·튜터, 연구실과 모바일 레이아웃을 검증했습니다. 자세한 기록은 `docs/VALIDATION.md`를 확인하세요.

모든 공격/방어는 메모리 속 교육 모형이며 실제 네트워크·SQL 엔진을 실행하지 않습니다. 튜터는 API 미연결 데모로 표시하며 Gemini 실연동은 안전한 백엔드가 필요한 향후 확장입니다. 연구 수치를 실제 탐지 성능으로 일반화할 수 없습니다.

# PR 본문

행동 목록에 미래·완료 카드가 길게 노출되던 게임 흐름을 현재 턴 선택 → AI 대응 결과 → 다음 턴 선택으로 바꿨습니다. RED는 상대 BLUE의 방어명과 효과·근거를 확인하고, BLUE는 상대 공격을 먼저 보고 방어를 고릅니다. 상단의 공격/방어 점수·위험·진행도와 접을 수 있는 대결 기록으로 결과를 비교합니다.

사용자 지정 주제 12개에 각각 5개의 상황·턴과 학습 요약을 추가했습니다. 초급은 대응 단서를 안내하고, 중급/고급은 직전 전술·위험·이전 결과에 따라 전략과 오판 비용을 달리합니다. 고급에는 추가 선택지가 있습니다. 규칙 기반이므로 Gemini 키 없이 작동하며 기술적 악용 코드나 외부 공격 요청을 실행하지 않습니다. 개인 Gemini 연결과 71개 주제 기본 도우미는 선택 기능으로 포함되어 있습니다.

기존 미션 1~5의 ID·규칙·점수와 저장 키 `cyber-duel:v1`, 퀴즈·기록은 보존합니다. 새 챕터는 별도 ID 101~112와 목록을 사용해 과거 기록이 다른 주제로 재해석되지 않게 했습니다. 기존 중간 게임을 이어갈 수 있고 새 결과 화면·난이도·이력도 저장합니다. 아카데미·연구실·프로젝트 소개·차콜/민트 디자인과 `/cyber/` 배포 경로를 유지했습니다.

# PR 본문

기존 아카데미 튜터는 12개 보안 자료만 검색했습니다. 이제 71개 보안·컴퓨터·네트워크·프로그래밍·정보 주제를 쉬운 비유·핵심 개념·예시로 설명하고 관련 개념을 최대 3개 함께 보여줍니다. 모르는 질문은 지원 범위를 안내합니다. 기본 모드는 자료 검색이며 생성형 AI라고 표시하지 않습니다.

왼쪽 AI 학습 도우미 메뉴와 아카데미에서 같은 화면을 사용할 수 있습니다. 도우미 바로 아래에는 개인 Gemini API 키와 모델 ID를 입력하고 실제 요청으로 연결을 확인하는 설정을 추가했습니다. 연결 후에는 질문 한 개씩 Google API로 전송합니다. 키는 컴포넌트 메모리에서만 사용하고 URL·코드·브라우저 저장소에 넣지 않으며 새로고침·페이지 이동·연결 해제로 폐기합니다. 인증·모델·할당량·네트워크 오류를 한국어로 안내하고 답변 요청 실패 시 기본 지식으로 돌아갑니다. 공유 서비스 키 제공에는 별도의 안전한 백엔드가 필요합니다.

기존 차콜/민트 디자인, 다섯 단계 게임, 학습 진도, 연구실, `/cyber/`와 배포 워크플로는 유지했습니다.

검증:
- 잠금 파일 기반 `npm ci`, `npm run build` 성공.
- `npm test`: 46개 통과, 실패·건너뜀 없음.
- `npm run test:browser`: RED/BLUE 각각 5단계와 저장·퀴즈·연구·모바일 회귀 검사 통과.
- `npm run test:tutor:browser`: 오프라인 기본 설명, 모의 Gemini 연결·답변·인증 실패·할당량 오류·취소, 키 비저장·새로고침 초기화, 모바일 화면 통과.
- `git diff --check` 통과.

실제 Gemini 키와 라이브 Google API 호출, GitHub Pages의 실제 배포는 검증하지 않았습니다. 개인 키를 연결 화면에 입력하면 실제 연결 확인을 실행할 수 있습니다. 자세한 검증은 `docs/VALIDATION.md`를 확인하세요.
